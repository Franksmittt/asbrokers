# ASSET calculator hero image prompts (001–017)

Use these for the **17 landing page heroes** only (`/calculators/asset-0XX-…` shells).  
Do **not** put text, logos, UI, charts, or watermarks in the frame — copy lives in the page.

## Delivery spec (same for all 17)

| Spec | Value |
|---|---|
| Aspect | **4:3 landscape** |
| Master size | **1600 × 1200** (or 1200 × 900 min) |
| Style | Warm documentary lifestyle, natural light, South African / Gauteng feel |
| Crop | Leave safe margins — image is `object-cover` in a rounded hero |
| Avoid | Purple gradients, neon glow, fake HUD/UI, stock handshake, text overlays, AS Brokers logo |

**Global negative (append to every prompt):**  
`no text, no letters, no numbers, no logo, no watermark, no UI, no charts, no graphs, no screenshots, no purple lighting, no neon, no stock handshake, no clipboard mockup with readable text, no distorted hands`

**Global look (prepend or keep in mind):**  
Warm afternoon light, soft stone and teal accents in the environment only (not as graphic overlays), authentic South African middle/upper-middle home or advisory setting, photoreal, shallow depth of field, premium but human — not corporate sterile.

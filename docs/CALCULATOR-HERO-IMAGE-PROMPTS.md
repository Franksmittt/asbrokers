# ASSET calculator hero image prompts (001–017) — v2

Use for the **17 landing page heroes** only. No text, logos, UI, charts, or watermarks in frame.

## Delivery spec (same for all 17)

| Spec | Value |
|---|---|
| Aspect | **4:3 landscape** |
| Master size | **1600 × 1200** (or 1200 × 900 min) |
| Socioeconomic read | **Upper-middle-class Gauteng** — quality finishes, calm prosperity, never flashy wealth porn, never struggling/poor |
| Style | Warm documentary lifestyle, natural light, South African |
| Crop | Safe margins — image is `object-cover` in a rounded hero |

**Class cues (use across prompts):** well-kept suburban/estate home, stone or warm timber interiors, good linen/cotton clothing, quality watches (subtle), decent kitchen appliances half in frame, landscaped garden — **not** mansions, supercars, champagne towers, or designer-logo overload.

**Global negative (append to every prompt):**  
`no text, no letters, no numbers, no logo, no watermark, no UI, no charts, no graphs, no screenshots, no purple lighting, no neon, no stock handshake, no clipboard with readable text, no distorted hands, no poverty aesthetic, no rundown interior, no cheap plastic furniture, no messy clutter, no supercars, no champagne spray, no gold-plated excess, no identical wardrobe across a series`

**Casting rule:** Each prompt = **different people and different outfits**. Vary age, gender mix, ethnicity (reflect SA), wardrobe colour, and setting so the set never looks like one couple reused 17 times.
